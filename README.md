# Python Assignment

This repository contains my solutions to two Python problems using the `datetime` and `json` modules.

## Files

| File | Description |
|------|-------------|
| `problem1.py` | Displays the current date and time |
| `problem2.py` | Converts a student dictionary into a JSON string |

## Problem 1: Current Date and Time

Uses the `datetime` module to display the current date and time in `YYYY-MM-DD HH:MM:SS` format.

**Example output:**

```
Current Date and Time: 2026-09-29 11:30:45
```

## Problem 2: Dictionary to JSON

Creates a dictionary with a student's name, age, and department, then converts it to a JSON string using the `json` module.

**Output:**

```
{"name": "Rahim", "age": 20, "department": "CSE"}
```

## How to Run

Make sure Python 3 is installed, then run each file from the terminal:

```bash
python problem1.py
python problem2.py
```
